Glossary and notation

Short reminders, not replacements for the calculations.

Representations and shapes

Scalar
One number. A vector is an ordered list; a matrix is a table with rows and columns.
Coordinate / dimension
A coordinate is one entry in a vector. Its dimension or width counts entries, not the number of concepts it understands.
Tensor / axis / shape
A numerical array and its indexed directions. Shape lists the length of each axis. See named array axes.
Dot product
Multiply corresponding coordinates, then add. It gives one scalar and depends on vector length as well as direction. See dot products.
Transpose
Exchange a matrix's row and column indices. In K⊤K^\topK⊤, the superscript means transpose, not a power.
Linear combination / span / rank
A linear combination adds scaled vectors. Their span is everything those combinations can reach. Rank counts independent directions in a matrix. See rank and information loss.
Embedding
A learned numerical representation retrieved by an ID or computed for an item. A token's initial embedding is not its later contextual state. See embeddings.
Cosine similarity
A direction comparison: divide a dot product by the product of the two nonzero vector lengths. It is undefined for a zero vector and does not establish factual relevance.
Pooling
Combine several vectors into one, for example by averaging only the permitted token rows. See retrieval representations.

Learning and probabilities

Parameter / activation / hyperparameter
A parameter is a stored value training can adjust. An activation is computed for one input. A hyperparameter configures the model or training procedure.
Derivative / partial derivative / gradient
A derivative describes local change. A partial derivative varies one independent input while holding others fixed. A gradient collects partial derivatives. See the calculus chapter.
Chain rule / backpropagation
Multiply local sensitivities along a path and add contributions from multiple paths. Backpropagation carries this calculation backward through saved operations.
Loss / optimizer / learning rate
Loss measures the prediction error chosen by the training objective. An optimizer changes parameters using gradients. The learning rate controls update size.
Probability / exponential / logarithm
A probability is a nonnegative share of a complete total of 1. The exponential exe^xex is positive; ln⁡a\ln alna asks which power of e gives positive a.
Logit / softmax / cross-entropy
A logit is a score before probability conversion. Softmax exponentiates scores and divides by their sum. For one observed target, cross-entropy is the negative logarithm of its probability.
Batch / epoch
A batch groups examples for a calculation. An epoch is a pass through the training dataset. The update count depends on batching and the training procedure.
Normalization
A specified rescaling or centering operation. Unit-vector normalization, attention normalization and layer normalization solve different problems; name the rule you mean.

Text, models and context

Token / vocabulary / token ID
A tokenizer selects text pieces from a configured vocabulary and returns their IDs. An ID is an address, not a meaning or embedding coordinate.
BPE / WordPiece / Unigram
Different tokenization procedures. BPE learns merge rules; WordPiece encoding follows vocabulary prefix choices; Unigram compares complete segmentation paths. See tokenization.
Expectation-maximization (EM)
For the Unigram toy calculation, distribute fractional credit across paths, count token uses and update probabilities. It is not the model's next-token generation algorithm.
Query / key / value
Queries and keys determine matching scores. Values provide the coordinates combined by the normalized weights. They are calculated from learned projections.
Attention head / cross-attention
A head performs a matching-and-mixing calculation. Self-attention derives roles from one sequence; cross-attention uses queries from one sequence and keys/values from another.
Mask / causal attention
A mask determines which keys a query may use. A causal next-token query cannot read future input positions. Position encodings do not enforce that rule.
Residual connection / feed-forward network (FFN)
A residual adds a branch output to its input. A Transformer FFN transforms each token row's features using shared parameters.
Rotary position embedding (RoPE)
Rotate query/key coordinate pairs by position-dependent angles. Standard RoPE does not directly rotate values. See the positional lessons.
Prefill / decode / KV cache
Prefill processes the known prompt. Decode processes new positions as generation proceeds. A KV cache stores compatible layer-specific keys and values for reuse.
MHA / GQA / MQA
Multi-head, grouped-query and multi-query attention differ in how query heads share keys/values. Fewer KV heads do not remove query heads.
FlashAttention / tile
A tile is a small processing block. Stable running sums let tiled attention avoid storing the full weight matrix without deleting permitted comparisons.
Complexity / payload / latency
Complexity describes operation growth; payload counts stored data; latency measures elapsed time. A saving in one does not establish a saving in another.
Retrieval-augmented generation (RAG)
An application obtains external information and supplies selected material to a model. It is not the attention operation itself and does not replace permission or trust checks.
