How to use this book

Who the book is for

You need basic arithmetic, not a prior course in linear algebra or calculus. Familiarity with arrays, loops and functions helps with the code. We explain mathematical notation separately from programming notation.

You can read without running code. When you do run an example, predict its output first, then compare the result with your reasoning.

Follow the dependencies

Read the first two chapters before the model calculations: they teach vectors, matrices, rates of change and gradients. Tokenization explains how text becomes IDs. Embeddings explain how IDs become usable representations. Neural networks build the forward and backward calculations. The Transformer chapter joins the parts, and the attention chapter examines matching, masks, caching and execution more closely.

If you already know a topic, use the contents and the glossary to find it. Do not skip a worked example merely because its vocabulary is familiar. Being able to calculate the example is a stronger check than recognizing its name.

A four-step reading routine

  1. Explain the goal. What question does this operation answer?
  2. Check the inputs. Name the coordinates, shapes, units and assumptions.
  3. Calculate. Write the intermediate values before looking at the result.
  4. Interpret. Say what the result tells you and what it does not tell you.

Try exercises with the answer hidden, then compare the reasoning. All exercise and interview answers are included in the EPUB and complete PDFs. Website answers can be expanded individually.

Reading across formats

The website has interactive experiments. The offline HTML uses local assets and native expandable answers. The EPUB is reflowable: text adjusts to the reader's page and type settings. Its diagrams and formula images can be enlarged; some ebook readers handle wide images and tables differently. The complete reading PDF has fixed pages and selectable prose. The print interior has a smaller fixed page with a binding margin.

In static editions, interactive controls are removed and the written examples remain. Keep a calculator handy for logarithms, exponentials and trigonometry. Reported decimals are rounded; use the exact expressions when comparing two calculation paths.
